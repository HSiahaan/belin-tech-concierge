# Berlin Tech Concierge — first static website draft

This site is intentionally static and lightweight. No WordPress, database or IONOS website package is required.

## Files
- index.html
- styles.css
- script.js
- impressum.html
- datenschutz.html

## Preview
Open `index.html` in a browser.

## Free hosting option: GitHub Pages
1. Create a GitHub repository, e.g. `berlin-tech-concierge`.
2. Upload these files to the repository root.
3. Settings -> Pages -> Deploy from branch -> main / root.
4. Add `berlintechconcierge.de` as the custom domain.
5. In IONOS DNS, enter the DNS records GitHub provides.

## Before publishing commercially
- Complete the Impressum.
- Adapt Datenschutz to the actual host/email provider.
- Activate `hello@berlintechconcierge.de` before using the email buttons.
- Confirm your side-business/employer and business-registration setup.
